# Invoice Generator

Create a clean, printable invoice in minutes. Free, no sign-up — your invoice is built in your browser and nothing is uploaded.

Free online tool site built for GitHub Pages. Static HTML, CSS and JavaScript only — no build step, no server, no tracking. Open `index.html` to start.

- Main tool: Invoice Builder (`tools/invoice-builder.html`)
- 4 tools, 20 guides, 20 images.
